BOOK CATALOGUE WEBSITE — QUICK START

FILES
- index.html: website page
- books.json: your 15 book records
- covers/: place your book cover image files here

PUBLISH ON GITHUB PAGES
1. Extract this ZIP on your computer.
2. Open your GitHub repository.
3. Click Add file > Upload files.
4. Upload index.html, books.json, and the covers folder contents (if any).
5. Click Commit changes.
6. In repository Settings > Pages, choose Deploy from a branch, select main and /(root), then Save.
7. Wait for GitHub Pages to publish your site.

EDIT BOOK DETAILS
Open books.json in a text editor. For each book, fill in publisher, price, writer, designer, edition, description.
For a cover image, put the image file in the covers folder and set its image value, for example:
"image": "covers/26102601.jpg"
Keep the quotes and commas in valid JSON format.

INDIVIDUAL BOOK LINKS
After your website is published, a book's detail link looks like:
https://YOUR-USERNAME.github.io/YOUR-REPOSITORY/?code=26102601
Replace the example username and repository with your real GitHub Pages address.
Create a QR code for each full link after the website is live.

IMPORTANT
The current file has the 15 codes and titles from your Excel screenshot. Prices, writers, designers, publishers, editions, descriptions, and actual cover images are blank because those details were not provided.
